# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Added horse metabolism support, including new icons for thirst and hunger and also an option in the config file to enable this sytem or not.
2. Fixed and added a missing configuration option related to SaltyChat only.

## Modified Files:

- client/tp-client_saltychat.lua
- client/tp-client_main.lua
- html/index.html
- html/js/script.js
- html/css/style.css
- html/css/style-bar-icons.css
- html/img (add `horse_thirst` and `horse_hunger` images).
- config.lua (check notes)
- fxmanifest.lua

## Notes

- Add on `config.lua`:

```lua
-- activates horse metabolism thirst and hunger icons and values.
Config.UseHorseMetabolism = false -- 1.0.4
```

